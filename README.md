# AutoSyndicate: Carbon District — Expansion v9

v9 продолжает слой `carbon_expansion_v8.js` через `js/carbon_expansion_v9.js`. Основные изменения: физические лимиты передач, новый race renderer, server-synchronized case rolls, SVG-слоты, расширенные профили, друзья и кланы.

## Гонка и КПП

Передачи теперь имеют физические пределы скорости:

| Передача | Предел |
| --- | ---: |
| 1 | 40 км/ч |
| 2 | 90 км/ч |
| 3 | 150 км/ч |
| 4 | 215 км/ч |
| 5 | 285 км/ч |
| 6 | до 380 км/ч, но не выше реального maxSpeed машины |

Что изменено:

- скорость больше не может продолжать расти на одной передаче до общего `maxSpeed`;
- RPM рассчитывается из положения скорости внутри диапазона текущей передачи;
- у ограничителя тяга прогрессивно снижается;
- попытка начать движение на 2–6 передаче приводит к stall и возврату на 1-ю после перезапуска;
- жёлтый сектор тахометра — GOOD SHIFT;
- зелёный сектор — PERFECT SHIFT с заметным кратким импульсом тяги;
- прокачка КПП расширяет окна, улучшает recovery RPM и уменьшает штраф ошибок;
- качество launch-control больше не даёт машине скорость до зелёного сигнала — обе машины стоят на 0 км/ч;
- качество старта превращается в стартовый коэффициент тяги после сигнала;
- AI проходит те же физические передачи и не разгоняется напрямую к целевой максимальной скорости.

## Ощущение скорости и FPS

- дистанция заезда сокращена до более динамичного диапазона;
- добавлен отдельный Canvas 2D слой speed streaks;
- Canvas использует тот же `requestAnimationFrame`, что и физика — второго race-loop нет;
- DOM HUD обновляется максимум 20 раз/с, физика и Canvas остаются привязаны к display RAF;
- devicePixelRatio Canvas ограничен;
- на слабых устройствах и при росте среднего frame time качество Canvas автоматически снижается;
- CSS speed-effects старой версии отключены, чтобы не гонять параллельную бесконечную анимацию;
- индикатор преимущества показывает метры/примерный time gap и визуальный marker относительно центра;
- смена лидера даёт отдельный visual pulse.

Цель рендера — 60 FPS на поддерживаемых мобильных устройствах Telegram. Абсолютные 60 FPS на любом железе гарантировать нельзя: итог зависит от WebView, устройства, температуры и фоновых процессов.

## Кейсы v9

В v9 результат кейса создаётся RPC `autosyndicate_roll_case` в Supabase.

Поток:

1. сервер создаёт уникальный `roll_id`;
2. сервер фиксирует `prize` и pity;
3. клиент использует **этот же prize object** как финальный элемент ленты;
4. позиция рассчитывается по реальному `offsetLeft/offsetWidth` финального DOM-элемента;
5. после остановки выдаётся тот же prize;
6. `roll_id` записывается в `caseAppliedRolls`, поэтому reconciliation не выдаёт его повторно;
7. незавершённые server rolls восстанавливаются после следующего входа.

Декоративные элементы ленты больше не вызывают функцию настоящего drop и не меняют pity.

Для v9 кейсов онлайн-сессия обязательна. Локального random fallback нет.

## Слоты «777»

- старые emoji-глифы заменены SVG-спрайтами;
- каждый барабан — вертикальная GPU-friendly strip-анимация через `translate3d`;
- финальный SVG-символ находится в самой ленте, а не рисуется поверх неё отдельным белым текстовым слоем;
- убран старый `reel.spin` animation loop;
- комбинации: BOLT, DIAMOND, STAR, CROWN, BAR, 777.

## Профили

В серверный профиль добавлены:

- `telegram_username`;
- победы и количество заездов;
- лучший 0–100 км/ч;
- текущая машина;
- rating;
- гараж.

После каждого завершённого заезда лучший 0–100 обновляется только если новый результат быстрее предыдущего.

## Друзья

Новый экран **Друзья**:

- добавление по AutoSyndicate Player ID;
- добавление по `@telegram_username`;
- входящие запросы;
- исходящие запросы;
- принятие/удаление;
- самодобавление запрещено;
- одна friendship-пара не может быть создана повторно.

## Кланы

Новый экран **Кланы**:

- создание клана с уникальным названием;
- один игрок может состоять только в одном клане;
- лидер может приглашать только игроков, которые уже являются его друзьями;
- принятие приглашения;
- управление составом;
- исключение участников лидером;
- лидер не может покинуть непустой клан, сначала нужно распустить состав.

Лиги рейтинга:

`Мантика → Бронза → Серебро → Золото → Платина → Карбон → Элита → Легенда`

Доступны:

- глобальный рейтинг;
- рейтинг текущего дивизиона.

## Обязательная миграция Supabase

Для существующей v8 базы:

1. Убедись, что **Authentication → Providers → Anonymous Sign-Ins** включён.
2. Если `schema_v8.sql` ещё не выполнялся — выполни его.
3. Затем выполни **целиком**:

```text
supabase/schema_v9.sql
```

Не запускай только отдельные куски social/case SQL: клиент v9 ожидает все новые таблицы, поля и RPC.

## Локальный запуск

```bash
python -m http.server 8080
```

Открыть:

```text
http://localhost:8080
```

Не запускай через `file://`.

## Проверки

- `node --check` для всех JS;
- отдельный VM harness для физических ограничителей передач;
- проверено: 1-я не превышает 40 км/ч, 2-я — 90 км/ч;
- проверено: старт на 2-й при 0 км/ч переводит двигатель в stall;
- проверена загрузка v9 extension с заглушками всех внешних API;
- case strip больше не вызывает настоящую reward/pity-функцию для декоративных элементов;
- Headless Chromium в этом контейнере не завершает процесс корректно даже на локальной странице, поэтому полноценный browser E2E не заявляется.
