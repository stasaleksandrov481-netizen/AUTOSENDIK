# AutoSyndicate: Carbon District — Expansion v8

В этой сборке гонка, КПП, соперники, кейсы, номера, рынок, тюнинг, рефералы, загрузка и сохранения собраны в один рабочий слой `js/carbon_expansion_v8.js` поверх основной Carbon-архитектуры.

## Главное в v8

### Гонка
- повышены максимальные скорости и темп набора скорости;
- сильнее разница между стоком и прокачанной машиной;
- чувствительный launch-control с качеством старта;
- AI сильнее давит, контратакует и получает короткие surge-окна;
- во время заезда появляются события давления, обгона и трафика;
- добавлены speed-effects и визуальная реакция HUD на высокий темп;
- финиш остаётся физическим: результат определяется прохождением дистанции, а не случайным победителем.

### КПП
- жёлтая зона = GOOD SHIFT и краткий бонус ускорения;
- зелёная зона = PERFECT SHIFT, более сильный boost тяги и меньшая потеря RPM;
- уровень КПП расширяет окна SHIFT, ускоряет набор оборотов и смягчает ошибки;
- бонусы ограничены по времени и масштабу, чтобы максимальная КПП не превращала заезд в автопобеду.

### Соперники
- 16 соперников вместо прежнего небольшого пула;
- имя, инициалы-аватар, стиль езды, любимые трассы, победы/поражения, машина и рейтинг;
- реплики и провокации до старта;
- отдельная реакция после победы или поражения;
- локальная история личных встреч с каждым соперником.

### Кейсы
- три типа кейсов с видимыми шансами;
- полноценная визуальная рулетка с лентой предметов;
- деньги, тюнинг, номера и редкие автомобили;
- история последних открытий;
- pity/guarantee механики, включая гарантию автомобиля для Syndicate Case;
- результат кейса фиксируется в save до завершения косметической анимации, поэтому перезагрузка во время прокрутки не должна съесть оплату без награды.

### Номера
- отдельная коллекция номеров;
- COMMON / RARE / EPIC / LEGENDARY / MYTHIC;
- обычные, редкие, «блатные» и LIMITED серии;
- платная прокрутка за SYND и pity на более редкий номер;
- номер устанавливается на конкретную машину и отображается в карточке автомобиля и рыночном лоте.

### Рынок
- `market_cars.vehicle_data` хранит полный snapshot машины;
- вместе с машиной передаются двигатель, турбо, КПП, шины, топливо, состояние, история тюнинга и установленный номер;
- мощность, build score и стоимость тюнинга при отображении пересчитываются из уровней деталей, а не доверяют произвольным полям JSON;
- после создания лота машина уходит в локальный escrow;
- при старте выполняется reconciliation активных серверных лотов, чтобы закрыть сценарий «сервер создал лот, браузер закрылся до локального удаления машины»;
- снятие лота возвращает весь snapshot.

### Тюнинг
- новые карточки деталей;
- сравнение текущего и следующего Stage;
- графические полосы мощности, разгона, окна SHIFT и сцепления;
- build score;
- стоимость установленного тюнинга;
- история установок, включая детали из кейсов.

### Реферальная система
Ссылка имеет вид:

```text
https://your-game.example/?ref=PLAYER_CODE
```

На стороне Supabase:
- referrer привязывается только один раз;
- самореферал запрещён;
- приглашённый получает 500 SYND за валидную привязку;
- после первой завершённой гонки — ещё 300 SYND;
- пригласивший получает 5% от подтверждённого роста `total_earned` реферала;
- начисления идут через отдельный ledger `referral_earnings` и выдаются идемпотентным RPC;
- прямые INSERT/UPDATE/DELETE в referral-таблицы у клиента отозваны.

### UI и загрузка
- emoji в интерфейсных HTML/JS удалены;
- навигационные и функциональные пиктограммы переведены на inline SVG;
- расширены мобильные стили;
- добавлены новые анимации гонки, кейсов и карточек;
- preloader считает прогресс загрузки автомобильных ассетов, показывает стадии и меняющиеся подсказки.

### Сохранения и устойчивость
- state schema v8;
- основной save + три вращающиеся резервные копии;
- нормализация новых полей при загрузке;
- восстановление из наиболее свежей валидной копии;
- защита от повторного открытия кейса во время анимации;
- рыночный escrow хранится в save.

## Запуск

Не открывай игру через `file://`. Из папки проекта:

```bash
python -m http.server 8080
```

Затем открой:

```text
http://localhost:8080
```

## Supabase — обязательно после обновления

1. В **Authentication → Providers** включи **Anonymous Sign-Ins**.
2. В **SQL Editor** выполни целиком `supabase/schema_v8.sql`.
3. В Realtime должны быть доступны `market_cars`, `chat_messages` и `pvp_challenges` — schema пытается добавить их автоматически.
4. В браузере используй только publishable/anon key. `service_role` в HTML/JS не добавлять.

`schema_v8.sql` можно выполнять поверх существующей v5-схемы: миграционные `ALTER ... IF NOT EXISTS`, функции и триггеры рассчитаны на повторный запуск.

Если ранее появлялась ошибка `autosyndicate_profile_guard(): authentication required` при запуске из SQL Editor, в v8 hotfix это исправлено: миграции под PostgreSQL-ролью `postgres` разрешены, а браузерные запросы без Auth-сессии по-прежнему блокируются. Для старой копии схемы можно сначала выполнить `supabase/HOTFIX_profile_guard.sql`, затем повторно запустить `schema_v8.sql`.

## Управление гонкой

На мобильном используются кнопки cockpit. На ПК:

- `W` / `↑` — газ;
- `S` / `↓` — тормоз;
- `Space` / `E` — переключение;
- `N` / `Shift` — N₂O.

## Проверки этой сборки

- `node --check` для всех JS-файлов;
- smoke-загрузка скриптов в реальном порядке;
- расширенный smoke для гаража, тюнинга, номеров, кейсов, подготовки/симуляции гонки, рефералов и достижений;
- проверка HTML на дублирующиеся `id`;
- разбор `carbon.css` через CSS parser;
- проверка интерфейсных HTML/JS на emoji.

Headless Chromium в контейнере не завершает полноценный рендер из-за системных ограничений окружения, поэтому browser E2E здесь не заявляется.
