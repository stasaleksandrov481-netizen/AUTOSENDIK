# AutoSyndicate: Carbon District v5

Большой рефактор проекта с сохранением визуального направления **NFS Carbon**: тёмный графит, карбон, жёлто-янтарные приборы, красные предупреждения, жёсткая гоночная типографика и минимум «обычных веб-панелей».

## Что изменено

- Полностью переполирован интерфейс без ухода от Carbon-стилистики.
- Новый гоночный cockpit: корректные шкалы, 6 передач, N₂O, телеметрия, клавиатурное управление на ПК.
- Исправлена физика и логика КПП: апгрейд `gearbox` теперь реально расширяет окно переключения.
- Добавлены районы карьеры, REP, HEAT и прогресс по территории.
- Добавлены ежедневные контракты с отдельными целями и наградами.
- Добавлены сортировка гаража, быстрый сервис, фильтры и сортировка автосалона.
- Добавлена история последних заездов и расширенная статистика профиля.
- Исправлены ложные достижения Blackjack/Boss Slayer и бесконечный секретный денежный бонус.
- Казино защищено от повторных кликов во время расчёта результата.
- Сохранения нормализуются и очищаются при импорте; размер импортируемого save ограничен.
- Убран дублирующий autosave-таймер.
- Добавлены CSP, `no-referrer`, safe-area и настройки reduced motion / compact HUD / haptics.
- Онлайн-функции переведены на Supabase Anonymous Auth + RLS. Старые политики `INSERT/UPDATE USING (true)` больше не используются.
- Серверные SQL-триггеры ограничивают спам чата, банковские лимиты, переходы статусов рынка и PvP.
- Выдача денег за проданный лот, перевод и PvP теперь сначала фиксируется серверным переходом состояния и только затем начисляется локально.

## Запуск

Не открывай `index.html` через `file://`. Запусти локальный HTTP-сервер из папки проекта:

```bash
python -m http.server 8080
```

Затем открой `http://localhost:8080`.

## Supabase: обязательная настройка

1. Открой **Authentication → Providers** и включи **Anonymous Sign-Ins**.
2. Открой **SQL Editor**.
3. Выполни целиком `supabase/schema_v5.sql`.
4. В Realtime должны быть доступны `market_cars`, `chat_messages` и `pvp_challenges`; SQL пытается добавить их в publication автоматически.
5. В клиенте допустим только publishable/anon key. `service_role` в HTML/JS добавлять нельзя.

Старые online-записи без `owner_uid` после перехода на v5 специально становятся read-only. Это лучше, чем автоматически «присвоить» их любой новой анонимной сессии.

## Управление гонкой

На мобильном: газ, тормоз, переключение, N₂O через кнопки cockpit. На ПК: `W/↑` — газ, `S/↓` — тормоз, `Space/E` — передача, `N/Shift` — N₂O.

## Проверка

Перед упаковкой выполнена статическая проверка синтаксиса всех JS-файлов через `node --check`, проверка HTML на повторяющиеся `id`, проверка обработчиков интерфейса и парсинг `carbon.css`. Headless Chromium в текущем окружении не завершил рендер из-за системных ограничений контейнера, поэтому полноценный browser E2E не заявляется.
